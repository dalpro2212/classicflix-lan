# ClassicFlix LAN

SPA tipo streaming, 100% offline. Vite + React + react-router-dom + Formik + Yup.

## Ejecutar
```bash
npm install
npm run dev
```

## Agregar películas
1. Copia los .mp4 a `public/videos/`
2. Agrega cada película a `public/movies.json` (id único, titulo, sinopsis, anio, categoria, director, duracion, video)
